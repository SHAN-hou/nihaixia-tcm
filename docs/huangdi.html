倪海厦黄帝内经课程 — 课程蒸馏笔记

医疗边界：本文件仅作课程学习、资料检索和中医理论整理；涉及真实症状、诊断、处方、剂量、针灸操作、急症、孕产儿童、肿瘤或附子等高风险内容时，不能作为个人医疗建议或自行操作依据，应咨询合格医疗专业人员。

课程规模: 19 课, 38.2 小时

这是一份基于您提供的19集《黄帝内经》课程摘要，为您精心提炼的结构化课程蒸馏笔记。

一、课程概览

课程主题：本课程是倪海厦老师对中医经典《黄帝内经》的深度精讲。课程以“天人合一”的整体观为核心，全面解析了中医的阴阳五行学说、脏腑经络运行、脉色望诊准则、针灸补泻心法以及疾病的传变规律。不仅涵盖了内科、妇科、奇难杂症的辨证论治，更将《易经》八卦、风水地理与人事变迁融入医学，还原了中医作为一门生命哲学的宏大格局。

目标受众：中医从业者、中医院校学生、中医爱好者，以及希望通过顺应自然规律来探寻长寿养生之道的普罗大众。

课程结构：全课由浅入深，从《上古天真论》的生命本源起笔，历经生理、病理、诊断、针灸实操，最终落脚于“上知天文、下知地理、中知人事”的高阶医道。课程打破了现代医学“以病名为核心”的局限，重塑了中医“同症同治”、“治病求本”、“胃气决死生”的实战思维。

二、课程体系图

本课程共19课，可划分为五个递进的核心模块：

  • 模块一：核心医理与生命哲学（第1-3课）
    • 包含内容：五行生克、情志致病、阴阳极性转换、女子生理周期、四季规律。
    • 模块目标：建立“形与神俱”、“阴平阳秘”的宏观中医世界观。
  • 模块二：辨证诊断与脉色合参（第4-8课）
    • 包含内容：脏腑官职、望诊逻辑、色脉合诊、四季平脉与病脉、胃气诊断。
    • 模块目标：掌握通过外在表象（气色、脉象）洞察内在脏腑生机的“见微知著”之法。
  • 模块三：针灸法则与六经传变（第9-12课）
    • 包含内容：六经辨证、天干地支与时辰、针灸深浅与呼吸配合、热病与疟疾的传变。
    • 模块目标：理解疾病由表入里的路径，掌握顺应自然节律的截断与针灸实操。
  • 模块四：奇难杂症与专病论治（第13-17课）
    • 包含内容：痿症（治痿独取阳明）、消渴（糖尿病）、水肿、妇科肿瘤、情志重症。
    • 模块目标：运用中医八纲辨证破解现代医学定义的“疑难杂症”，强调整体水液代谢与阳气温化。
  • 模块五：天人合一与高阶医道（第18-19课）
    • 包含内容：洛书九宫与家庭定位、诊病五过、五运六气、医者心法。
    • 模块目标：突破纯肉体治疗，将空间风水（运）与社会人事结合，达到大医从容的境界。

递进关系：从“明理”（模块一）到“识病”（模块二），再到“治法”（模块三、四），最终升华为跨越医学边界的“医道”（模块五），形成闭环。

三、逐课精要

  • 第01课：解析人类生老病死规律，强调养生需“形与神俱”，揭示情志相克与女性7年周期的生理奥秘。
  • 第02课：阐述阳气卫外的重要性，指出风邪为百病之始，饮食五味需调和以防脏腑偏衰。
  • 第03课：深究阴阳寒热的极性转换，确立“同症同治”原则及“泻南补北”的高阶治则。
  • 第04课：确立心脏为“君主之官”不受癌症侵袭的特质，强调“中医看水”的三焦气化观念。
  • 第05课：剖析肝脏藏血与睡眠的关系，定下“胃气决死生”的终极临床救治底线。
  • 第06课：传授四季针刺深浅法则，详述十二经脉气绝危象，强调辨别阴阳为诊断第一要务。
  • 第07课：拆解寸关尺定位，指出贫血需治水（补肾平火），糖尿病实为湿热积聚而非纯遗传。
  • 第08课：以“胃气为本”贯穿四季脉象，解析“实则泻其子，虚则补其母”的五行截断病机法。
  • 第09课：讲解六经传变与气机升降，揭示中药五味法则与顺应天干地支时辰的治病玄机。
  • 第10课：传授针灸补泻与呼吸配合的心法，强调医者需“用神”看病，问得越少医术越高。
  • 第11课：梳理热病皆由伤寒转化的病机，推崇生病初愈时以米汤养护脾胃的食疗智慧。
  • 第12课：剖析疟疾寒热交替的成因，指出严重呕吐为“胃为肾之关”失守的肾衰危象。
  • 第13课：传授治鼓胀、血枯等奇方，强调医者当有替患者承担烦恼的父母心与治神之术。
  • 第14课：揭示肢体萎缩（痿症）根源在于“热”伤津液，确立“治痿独取阳明”的经典法则。
  • 第15课：批判糖尿病遗传论，指出痛是“积累的压力”，治虚证需守“无损不足”的底线。
  • 第16课：阐明妇科肿瘤源于下焦阴寒，小儿流鼻血为正常排热，下针绝不可误刺五脏。
  • 第17课：辨别风寒表证，详解奇经八脉病机，确立通过“肾街”“胃街”排水利尿的治水法则。
  • 第18课：融合易经八卦与九宫格，揭示家庭名位不符的致病机理，展现通过改风水治大病的绝学。
  • 第19课：对比人与鼠的阴阳反差，警告不可犯“诊病五过”，医者面对暴疾必须“从容”心定。

四、跨课程主题图谱

1. 胃气为本，决断生死 * 出现位置：第05、08、11、12课。 * 核心观点：无论脉象多么复杂，只要有“缓而有力”的胃气即有生机；治病绝不能伤胃气，大病初愈最宜喝米汤；无法进食常是肾关失守、命悬一线的危象。

2. 阳气主导与水液气化 * 出现位置：第02、04、14、16、17课。 * 核心观点：“中医看水，西医看血”。人体70%是水，阳气是推动水液运行的动能。阳气受阻会导致湿气、肿瘤积聚；女性保持下焦温热是预防妇科肿瘤的核心。

3. 同症同治与摒弃病名 * 出现位置：第03、09、15课。 * 核心观点：中医治“症”不治“病”。只要表现出的症状相同（如阴阳虚实寒热相同），不管西医叫什么病名（肿瘤、过敏等），都用相同的方法治疗，智者查同。

4. 顺应四时与天人相应 * 出现位置：第01、02、06、08、09课。 * 核心观点：人体的脉象、发病规律、针灸深浅必须与四季（春生夏长秋收冬藏）及天干地支相对应。例如“冬伤于寒，春必病温”，违背自然规律是早衰和发病的根源。

5. 情志、人事与空间风水 * 出现位置：第01、13、18、19课。 * 核心观点：情志失调会导致脏腑受损（如恐伤肾）。疾病不仅是肉体问题，还受社会地位变迁（诊病五过）和居住方位（洛书九宫）的深刻影响，需综合调理。

五、关键概念词汇表

课程还结合大量板书，直观展示了面部五官与脏腑的对应关系，以及阴阳分隔、气机逆乱导致的死症判定。通过“色诊”教学，倪师指出面见青黑主痛、白主寒、黄红主热的辨证逻辑，并解析了因受大寒深至骨髓导致的长期头痛。关于胆虚导致的口苦及胎儿期受惊引发的癫痫，课程也给出了明确的病理解释。倪师在课中多次强调中医的压力观，指出“痛就是积累起来的压力”，治疗应疏导积滞而非单纯止痛。针对消渴，他留下了引人深思的金句：“这是生活习惯的遗产，不是身体的DNA遗传。”整堂课旨在教导学生通过八纲辨证洞察病源，还原中医“治病必求于本”的理论精髓。

黄帝内经16 (113.7分钟)

黄帝内经16

本期视频为倪海厦老师主讲的《黄帝内经》第16集，核心围绕人体脏腑的阴阳表里关系、病机传变，以及针灸的“刺要论”与“刺禁论”展开。结合黑板上详细的脏腑图示与九宫格板书，倪师深刻剖析了自然节气与人体五脏的对应规律，讲述了如何通过辨别阴阳来精准把握病症，并明确指出了中医判定人体健康的绝对标准。

课程中详细阐述了四个重要知识点：第一，脏腑的连带与自救反应，心火必须下沉至小肠，且心胃相连，有时反常的胃口大增实则是心脏出问题后机体本能寻找能量自救的反射；第二，小儿流鼻血的生理机制，指出14岁以下阳气旺盛的小孩，在感冒发烧时流鼻血是机体抗邪外解、疏散内热的正常现象，并非病态；第三，妇科肿瘤的成因，强调女子下焦（子宫卵巢）必须依靠小肠的热量保持温热，若体内阴寒过盛则易导致淤血凝结成块，进而形成肿瘤；第四，针灸的深浅原则与禁忌，下针须做到“无过不及”，病在皮刺皮、病在骨刺骨，绝对不可误刺五脏核心，否则会引发严重的脏器损伤。

倪师在授课中反复强调阴阳平衡的重要性，不仅是生理，就连情志失常也源于此：“任何的恐惧，什么样的情绪都是阴阳失去平衡造成的。”此外，他给出了检验治疗是否正确的最简标准：用药后若手脚变温暖，说明阳气得复；若越治脚越冷，则是耗损阳气。正如他针对女性健康总结的金句：“我们随时让太太小姐们保持下交是温热的，没有肿瘤会累积在里面。”这不仅是治病之法，更是日常养生的核心智慧。

黄帝内经17 (178.7分钟)

黄帝内经17

本节课程重点讲解了《黄帝内经》中的《骨空论》与《水热穴论》，深入剖析了风寒表证的针灸治法、奇经八脉的病理特征，以及人体水液代谢与脏腑的密切关系。讲师结合大量黑板板书与经络脏腑图解，生动还原了中医经典中“标本兼治”的临床辨证与治疗思维。

课程首先明确了外感风寒的辨证纲领，指出“伤于寒，病人无汗；伤于风，病人有汗”，并给出了取风府、攒竹等穴的针灸方案。其次，详细解析了任、督、冲脉的病机，例如冲脉病发“逆气里急”可取公孙穴治疗。在讲解“灸寒热法”时，强调无论遇到何种疾病（如疟疾、破伤风等），只要出现往来寒热，皆可取大椎、绝骨等穴按年龄壮数施灸。此外，课程重点解读了水肿的深层病理，指出肾为水脏、肺为标，阐明了通过“肾街”与“胃街”等特定穴位（如中注、大巨等）排水利尿的治疗法则，并板书总结了“左病治右，右病治左”的巨刺与缪刺原则。

正如课中所引述的经典金句：“肾者，胃之关也，关门不利，故聚水而从其类也。上下溢于皮肤，故为胕肿。”这句话精准道破了水肿病的根源在于肾关不利。本课不仅传授了经络穴位的具体刺法与补泻原则，更深刻展示了中医将人体脏腑与自然气化相参的整体观智慧。

黄帝内经18 (108.4分钟)

黄帝内经18

本集课程的核心主题是“天地定位与中医人事”。讲师将《黄帝内经》的阴阳医理与《易经》的八卦九宫深度结合，指出真正的中医不仅要治疗肉体受风寒或情志失调引发的疾病，更要懂得运用综合智慧来解决患者的心理障碍、家庭矛盾甚至横祸灾厄。课程强调，人居于天地之间，家庭成员的“名分”（行）必须与居住方位的“神”相匹配，身心才能安泰，医道也因此得以长久传世。

结合黑板上丰富的图文推演，课程重点拆解了以下四个核心知识点：第一是“洛书九宫与八卦定位”，讲师通过板书详细演示了数字平衡（如492、357、816）与家庭成员方位的对应，明确西北乾位为父、西南坤位为母、正东震位为长男等布局；第二是“名位不符的致病机理”，例如长子若错住西方（少女位）易导致性向改变或精神错乱，长女错住西北（父亲位）则会性格越俎代庖、过于老成，通过“房间归位”结合中药方剂即可根治疑难杂症；第三是“生育与方位的关系”，利用阴阳方位（南为阴生女，北为阳生男）来指导居室布置以改变生育运势；第四是“望诊中的病色与灾色”，结合天干地支五行图，讲师教导如何通过观察面部青、赤、黄、白、黑五色的“暗而无光”来判断脏腑病情，并严格区分了病色与灾祸之色。

课程中充满了对传统医学格局的深刻洞察，正如讲师所言：“命是天注定的，运操之在我。” 以及 “把地理三分之一加上人事（医学）的三分之一，加起来就是三分之二，就大于命。” 这种将空间地理（运）与高超医术（人事）相结合的治疗观，打破了单纯依赖药物的局限。配合视频末尾对风水罗盘的实操演示，生动诠释了中国传统哲学中“天人合一”在医疗实践中的顶级应用，展现了中医“上知天文，下知地理，中知人事”的至高境界。

黄帝内经19

本期《黄帝内经》课程（第19集）核心围绕宋本补全的第七十二篇《刺法论》以及第七十五至七十七篇（《著至教论》《示从容论》《疏五过论》）展开。讲师深入浅出地剖析了中医的灵魂——阴阳理论，并结合板书详细图解了天地人之间的阴阳交接关系。课程强调，为医者不仅需精通脉诊与五行生克的病机转化，更要在临证时保持“从容”的心态，透过复杂的表症看清病发于哪一核心脏腑，切忌被假象迷惑。

结合视频画面与讲解，课程输出了以下核心知识点： 第一，阴阳的取象比类。讲师以“人秉天阳而立，鼠秉地阴而趴”生动揭示了人与老鼠的阴阳属性完全相反，以此指出盲目用老鼠做药物实验并用于人体的荒谬性。 第二，因龄制宜的诊断法则。诊病需看年龄特征：老年人脏气已衰，重在查骨（肾）；少年人脏气强盛，重在查筋（肝）；而壮年人劳碌易伤，重在查腑。 第三，避免“诊病五过”。结合板书的“寸关尺”及脉证图解，强调绝不能单靠摸脉诊病。必须细问患者的社会地位变迁（如先富后贫、先贵后贱）与情绪起伏，因为情志的大起大落会直接导致精气内伤。 第四，疫气与五运六气。在《刺法论》的讲解中，板书重点展示了“疫气之说”与预防原则，并结合“乙巳、庚癸”等天干地支符号，推演了疫病与天地气运的关系。
