医疗边界：本文件仅作课程学习、资料检索和中医理论整理；涉及真实症状、诊断、处方、剂量、针灸操作、急症、孕产儿童、肿瘤或附子等高风险内容时，不能作为个人医疗建议或自行操作依据，应咨询合格医疗专业人员。

从用户主诉反推课程中的辨证分水岭。使用时先收集缺失信息，再进入六经和方证模块。仅供学习。

发热、恶寒、汗出

必须问：

  • 有汗还是无汗。
  • 恶风还是恶寒。
  • 身痛、项背强、喘、烦躁有无。
  • 口渴、小便颜色、大便情况。
  • 咽喉是否干燥，尺脉是否迟微。

课程辨法：

  • 有汗、恶风、脉缓：太阳中风，桂枝汤方向。
  • 无汗、体痛、脉紧：太阳伤寒，麻黄汤方向。
  • 项背强几几、无汗、恶风：葛根汤方向。
  • 无汗烦躁、表寒里热：大青龙汤方向。
  • 但热不寒、大渴：阳明经热，白虎汤方向。

禁忌：

  • 咽干、淋家、疮家、尺脉迟微，课程均列为发汗禁忌。
  • 少阴病脉微细但欲寐不可按太阳病发汗。

往来寒热、胸胁苦满、恶心

必须问：

  • 寒热是否“来回发作”，还是持续高热。
  • 是否胸胁苦满、口苦、恶心。
  • 女性是否月经期。
  • 是否已有误下、误汗。

课程辨法：

  • 少阳枢机不利：小柴胡汤方向。
  • 一半太阳一半少阳：柴胡桂枝汤方向。
  • 经期外感：热入血室，课程强调直接和解，不发汗。
  • 少阳兼阳明实热：柴胡加芒硝汤方向。

口渴与饮水

必须问：

  • 渴欲饮水还是口渴不欲饮。
  • 小便深黄/清白/不利。
  • 有无高热、大汗、大便结。

课程辨法：

  • 阳明大热大渴：白虎汤或白虎加人参汤方向。
  • 蓄血常见口渴不欲饮、小便自利。
  • 少阴自利而渴，小便色白，偏下焦寒水不能气化。
  • 水逆：喝水反吐，五苓散方向。

便秘

必须问：

  • 几天不便，是否痛苦。
  • 是否放屁，是否能食。
  • 大便气味和形状：臭秽、羊屎、黑便。
  • 小便深黄还是清白。
  • 腹部喜按还是拒按，天枢是否压痛。

课程辨法：

表现 课程辨证 方证方向
小便深黄、大便臭、腹拒按 热实便秘/阳明腑实 承气汤类
不放屁、无食欲、谵语、天枢剧痛 阳明腑实重 大承气汤
尚能食且放屁 阳明腑实轻 小承气汤
羊屎状便 脾约、津液枯竭 麻子仁丸
十日不便无痛苦、小便清白 寒实便秘 温阳去寒方向
善忘、黑便、少腹硬满、小便自利 蓄血 抵当汤方向

高风险：

  • 承气汤急下存阴为危重理论，不可自行用药。
  • 急性腹痛、停止排气排便、呕吐、发热、神志异常需急诊。

下利、腹泻、假水泻

必须问：

  • 大便是清稀、臭秽、便脓血，还是清水样。
  • 腹部喜按还是拒按。
  • 小便深黄还是清白。
  • 口渴与否，肛门灼热与否。
  • 是否误下后发生。

课程辨法：

  • 热利：葛根黄芩黄连汤（葛芩连汤）方向。
  • 寒利：桂枝人参汤、四逆汤辈方向。
  • 太阴自利不渴：温中利湿，利小便。
  • 少阴下利清谷、脉微欲寐：少阴里寒，高风险。
  • 热结旁流：看似拉清水，实则腹拒按、小便深黄、里面燥屎堵塞，大承气汤急下方向。
  • 少阴便脓血：桃花汤方向。

腹胀、腹痛、腹诊

必须问：

  • 喜按还是拒按。
  • 腹满时痛还是持续剧痛。
  • 小便颜色。
  • 大便通不通、是否放屁。
  • 痛在少腹、心下、胸胁还是全腹。

课程辨法：

  • 拒按：偏实，阳明燥屎、蓄血、结胸等方向。
  • 喜按：偏虚，虚胀、太阴寒湿方向。
  • 少腹急结或硬满，小便自利：蓄血方向。
  • 胸满用枳实思路，腹满用厚朴思路，课程多次强调厚朴/枳实分工。

睡眠、烦躁、心悸

必须问：

  • 是否汗吐下之后出现。
  • 是虚烦不得眠，还是昼日烦躁不得眠。
  • 是否心中烦不得卧、心悸、脉结代、胸痛。
  • 手足温度、大便、胃口。

课程辨法：

  • 汗吐下后虚烦不得眠：栀子豉汤方向。
  • 发汗伤阳，昼日烦躁不得眠：干姜附子汤方向。
  • 发汗后心下悸：桂枝甘草汤方向。
  • 脉结代、心动悸：炙甘草汤方向。
  • 少阴心中烦不得卧：黄连阿胶汤方向。

心脏恢复四指标：

  • 恢复安眠。
  • 大便正常。
  • 手脚温热。
  • 无胸痛。

小便不利、尿频、尿血、结石

必须问：

  • 小便不利还是尿频。
  • 尿色深黄、清白、血尿。
  • 口渴、发热、下利、腹痛。
  • 是否有结石诊断或绞痛。

课程辨法：

  • 水液代谢失常、水逆：五苓散方向。
  • 泌尿结石、小便不利兼阴虚火旺/血尿：猪苓汤方向。
  • 少阴下焦寒水不能气化：小便色白、压迫性尿频，真武汤/四逆类高风险方向。

手足冷、厥逆

必须问：

  • 冷到手指脚趾，还是到腕踝、肘膝。
  • 是否下利清谷、脉微细、但欲寐。
  • 是否口渴、烦躁、腹痛、小便颜色。
  • 是否胸痛、气短、意识异常。

课程辨法：

  • 手足末梢厥寒、血脉寒凝：当归四逆汤方向。
  • 下利清谷、脉微、手足厥冷：四逆汤辈方向，高风险。
  • 四逆但气机郁滞：四逆散方向，与四逆汤不同。
  • 厥阴厥：阴阳不相顺接，需辨寒热真假。

现代安全：

  • 手足冷伴胸痛、呼吸困难、意识改变、低血糖样表现、休克样表现，必须急诊。

妇科、血证、瘀血

必须问：

  • 是否经期、经前后。
  • 少腹痛是否急结/硬满。
  • 小便是否自利。
  • 是否黑便、善忘、肌肤甲错。

课程辨法：

  • 经期感冒：热入血室，小柴胡汤方向，绝不普通发汗。
  • 少腹急结、小便自利、口渴不欲饮：桃核承气汤方向。
  • 少腹硬满、善忘、黑便：抵当汤/丸方向。
  • 干血痨、肌肤甲错：课程联系瘀血久病与重大病机。

高风险：

  • 妇科出血、孕产妇、剧烈腹痛、疑似急腹症或肿瘤，必须就医。
